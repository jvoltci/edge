Static assets for jvoltci.github.io/tools. No code, no build — just files.

The tools app never uploads what you open in it. Speech recognition needs a model from somewhere, and fetching it from a third-party CDN would tell that CDN you opened the tool. This repo exists so it doesn't have to: it sits on the same origin as the app, one directory over.

Served here

Path Size What
models/whisper-tiny/ 45 MB Whisper tiny, int8 — fast, rougher
models/whisper-base/ 81 MB Whisper base, int8 — slower, better
ort/<version>/ 35 MB ONNX Runtime wasm, plain + asyncify

Notes

Both models are multilingual, not the .en variants — they quantise to identical sizes, so English-only builds trade 98 languages for nothing. The runtime path is version-pinned so a stale pairing 404s loudly instead of loading a runtime that disagrees with its caller. Whisper small is absent because its decoder is 156 MB and GitHub blocks any single file over 100 MiB, with Git LFS unavailable on Pages.
